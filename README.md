## 🧠 Overview

Ankama Launcher is a centralized desktop application that brings Ankama games and entertainment into one convenient hub. It allows players to install, update, and launch supported titles, including games from the DOFUS and WAKFU universes. The interface also provides access to news, video content, and webtoons from the wider Krosmoz world. With multi-account support and the ability to run multiple game sessions, Ankama Launcher helps players manage their gaming activity without switching between separate launch tools.

## Additional Information for Windows Users

Install the launcher on a drive with sufficient available storage, and keep it and your installed games updated. The launcher's installation location is selected during setup, while individual game locations can be configured separately. If a game fails to start or update, restart the launcher and use the available repair options. For persistent problems, diagnostic logs can help identify the cause. Multi-account availability and certain security features depend on the game and account configuration.
